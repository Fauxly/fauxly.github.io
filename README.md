## 📥 Add Repo

```
https://fauxly.github.io/
```

Open PurePKG on your Apple TV → **Sources** → **Add** → paste the URL above.

> 💡 **Tip:** Copy the URL on iPhone — it will transfer to Apple TV automatically via Universal Clipboard.

## ✅ Compatibility

- Apple TV 4K (1st gen)
- tvOS 17.0 and below
